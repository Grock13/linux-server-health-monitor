# Linux Server Health Monitor

A simple Bash script that collects basic Linux server health information.

## Checks

- Date and time
- Hostname
- Current user
- System uptime
- Memory usage
- Disk usage
- Top memory-consuming processes
- Network information
- Disk usage warning

## Run

```bash
chmod +x health-check.sh
./health-check.sh
